# Troubleshooting Guide

This directory contains documentation for common issues and their solutions when working with Solid UI Toolkit components.

## Available Guides

- **[Scrollbar Layout Issues](scrollbar-layout-issues.md)** - Common problems when integrating the custom Scrollbar component into different layout contexts (modals, flexbox containers, etc.)

## Contributing

When documenting a new issue:

1. Create a new markdown file with a descriptive name (kebab-case)
2. Follow the structure:
   - Overview
   - Problem Statement
   - Root Causes
   - Real-World Examples
   - Prevention Checklist
   - Debugging Steps
3. Include code examples showing both incorrect and correct approaches
4. Reference related components and files
5. Update this README with a link to the new guide

## Format Guidelines

- Write in English (professional, senior-level documentation)
- Use clear, descriptive headings
- Include code examples with ❌/✅ markers
- Provide step-by-step debugging procedures
- Link to relevant MDN documentation when appropriate
- Include file paths to actual implementation examples
